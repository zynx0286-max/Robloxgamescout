# Step 6.4 — Create Filter System

Create:

```text
filters.py
```

Add:

```python
def passes_filters(game, settings):

    if game["visits"] < settings["minimum_visits"]:
        return False


    if game["playing"] < settings["minimum_players"]:
        return False


    return True
```
