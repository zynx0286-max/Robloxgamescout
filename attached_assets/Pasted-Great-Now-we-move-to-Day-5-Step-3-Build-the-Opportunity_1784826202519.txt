## Step 3.1 — Add Analysis Logic

Open:

```text
opportunity.py
```

Paste:

```python
def analyze_game(game):

    reasons = []

    score = game.get("score", 0)
    trend = game.get("trend_score", 0)
    growth = game.get("growth", 0)


    if trend >= 80:
        reasons.append(
            "🔥 Strong trending activity"
        )


    if growth >= 100:
        reasons.append(
            "📈 Extremely fast player growth"
        )

    elif growth >= 50:
        reasons.append(
            "📈 Positive player growth"
        )


    if game.get("source") == "RoTrends":
        reasons.append(
            "🌐 Found through RoTrends"
        )


    if game["playing"] >= 5000:
        reasons.append(
            "👥 High active player count"
        )


    if not reasons:
        reasons.append(
            "📊 Normal activity"
        )


    return reasons
```

# Step 3.2 — Add Opportunity Rating

Add below it:

```python
def get_opportunity_level(game):

    score = game.get("score", 0)
    trend = game.get("trend_score", 0)


    total = score + trend


    if total >= 150:
        return "🔥 HIGH OPPORTUNITY"


    elif total >= 90:
        return "📈 WATCHLIST"


    else:
        return "⚪ NORMAL"
```
