## Step 2: Test slash commands

In your Discord server, type:

```text
/
```

You should see commands like:

* `/scan`
* `/trending`
* `/watchlist`
* or whatever you've already implemented.

If no commands appear after about a minute, tell me—that usually means the command sync isn't working.

---

## Step 3: Test every existing command

Run each command you already have.

Check for:

* Does it respond?
* Does the embed look correct?
* Are there any errors in the console?
* Does it take too long?

Don't worry about making them look perfect yet—just verify they work.

## Step 4: Test buttons

If your embeds include buttons like:

* Claim
* Accept
* Reject
* Watch

Click each one and verify:

* The interaction succeeds.
* No "Interaction Failed" message appears.
* The correct action happens.

## Step 5: Verify the database

Run a command that should save data (such as adding to a watchlist).

Then confirm your SQLite database file (for example, `scout.db`) is created and that the data is actually being written.
